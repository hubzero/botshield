About this site

Crestline is a fictional research library used as the dev playground for mod_botshield, an Apache 2 module that issues tiered proof-of-work and captcha challenges to suspected bots.

What lives where

  • / — this marketing-style home page, cheap to serve, should almost never trip a challenge.
  • /search.html — form that scrapers love. Good target for rate-limit penalties.
  • /login.html — credential-stuffing target. Deserves the aggressive tier even for first-time visitors.
  • /api/* — JSON endpoints. Most bot traffic we see goes here.
  • /assets/* — static assets. Must never be challenged or the page breaks.

Why a dev site at all

We need real HTTP requests flowing through Apache so we can watch the module's decisions under representative traffic — cookie state, rewrite interaction, output filtering, the whole cycle. Unit tests can't cover that.
